# Projekt 3

Ein modernes Landing-Page-Projekt, das mit HTML und CSS erstellt wurde. Die Website enthält verschiedene Bereiche wie Navigation, Hero-Bereich, Artikel, Galerie, Features, Kundenbewertungen und Teammitglieder.

## Technologien
- HTML
- CSS
- Font Awesome
- Google Fonts

## Projektstruktur
- `index.html` – Hauptstruktur der Webseite
- `css/normalize.css` – CSS-Reset
- `css/elzoro.css` – Haupt-Stylesheet
- `imgs/` – Bilder und Grafiken

## Beschreibung
Dieses Projekt wurde entwickelt, um eine moderne und ansprechende One-Page-Webseite zu erstellen. Dabei wurden grundlegende Frontend-Fähigkeiten wie Layoutgestaltung, Styling und responsives Design angewendet.

## Ziel
Das Ziel war die Erstellung einer professionellen Landing Page als Übung in der Webentwicklung.
